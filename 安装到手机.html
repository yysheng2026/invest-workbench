数据默认存在你自己的设备上，不上传任何服务器
直接打开工作台 →

多设备同步 先做这个

电脑和手机是两套互不相通的本地存储，本来就不会自动一样。按下面做一次， 之后就自动同步了。

第 1 步 · 申请一个免费的 Key（约 1 分钟）
  1. 打开 jsonbin.io/login，找 Sign up 注册（免费版就够用）
  2. 登录后打开 jsonbin.io/app/api-keys
  3. 复制那里的 API Key（一串以 $2a$10$ 开头、几十位的字符）
第 2 步 · 在已有数据的那台设备上配置
  1. 打开工作台 → 设置 → 多设备同步
  2. 把 Key 粘进「API Key」，Bin ID 留空
  3. 点 上传到云端（会自动创建 Bin 并把 Bin ID 填回去）
  4. 勾上 自动同步
第 3 步 · 用配对链接让另一台设备一秒接上
  1. 点 生成配对链接 → 复制链接
  2. 用微信发给自己（文件传输助手）
  3. 在另一台设备上用浏览器点开这条链接 → 看到「已配对 / 正在取回云端数据」 就说明接上了
  4. 如果你还要把它加到主屏幕：就在这一步（链接还带着 #sync=… 口令时） 点 分享 → 添加到主屏幕
⚠️ 链接里含你的 Key，只发给自己，别发到群里。
⚠️ 顺序别反：先打开配对链接 → 再加到主屏幕。反过来的话， 存到主屏的快捷方式里没有这段口令，打开就是空的。
主屏 App 打开还是空的？粘一次配对码就好

iPhone 的主屏 App 用的是独立存储空间，和 Safari 不共享数据（这是 iOS 的规则， 不是本工作台的问题）。所以配好了 Safari、主屏里却还是空的，是正常的。

  1. 打开主屏 App → 设置 → 找到 粘贴配对码
  2. 把刚才那条链接（或 #sync= 后面那段码）粘进去 → 点 应用配对
  3. 本机是空的会自动把云端数据取回来；不是空的会挂橙色提示条等你确认

之后怎么用：改完东西十几秒内自动上传；另一台设备打开时， 顶部会出现橙色提示条告诉你「云端有更新」，你点了才会覆盖本机 —— 本机数据永远不会被偷偷替换。

手机 · 装成 APP 推荐

用手机浏览器打开本页，按下面步骤加到主屏。之后点主屏图标就能像 App 一样全屏打开， 断网也能用（数据在手机本地）。

iPhone / iPad（Safari）
  1. 点底部中间的 分享 按钮（方框＋向上箭头）
  2. 往下找到 「添加到主屏幕」，点它
  3. 右上角点 添加
Android（Chrome / Edge / 华为 / 小米浏览器）
  1. 点右上角 ⋮ 菜单
  2. 选 「添加到主屏幕」 或 「安装应用」
  3. 确认即可
⚠️ 用微信内置浏览器打开的话，右上角菜单里没有「添加到主屏幕」。 请点右上角 ⋯ → 在浏览器打开，再用系统浏览器加到主屏。

电脑 · 加到桌面 / 任务栏 离线可用

电脑上不用装任何东西，用浏览器（Edge 或 Chrome）打开本页就行：

  1. Edge：右上角 ⋯ → 应用 → 将此站点作为应用安装
  2. Chrome：右上角 ⋮ → 投放、保存和共享 → 将网页作为应用安装
  3. 装完会有独立图标，可固定到任务栏 / 桌面，打开没有地址栏，断网也能用

另外网页版本身就有离线缓存，只要打开过一次，之后没网也能进。

电脑 · 本地文件版（可选） 自动备份

想要「数据存成电脑上的一个真实文件」而不是浏览器里时，才用这个。 数据写在 投资实证工作台\data\save.json，每天自动留一份备份。

  1. 在 OneDrive\【我的工作台】\投资实证工作台 这个文件夹里 （注意不是 Windows 桌面），找到 投资实证工作台.bat
  2. 双击它，会弹出独立窗口
  3. 也可以用右键 → 发送到 → 桌面快捷方式，以后从桌面进
⚠️ 这一步不是必须的。日常用网页版就够了，只是网页版的数据存在浏览器里， 清理浏览器数据会丢 —— 记得定期在「设置」里导出备份或开云同步。

出问题怎么办

  1. 加到主屏后打开是空的 → 主屏 App 是独立存储空间，进 设置 → 粘贴配对码，把配对链接再贴一次（见最上面那张卡片的最后一步）
  2. 另一端一直是空的 → 在那台设备点「从云端恢复」（自动配置只管连上，不会擅自覆盖你的数据）
  3. 没有出现提示条 → 先确认两台都勾了「自动同步」；再确认 Bin ID 两边一致
  4. 提示同步失败 → 多半是 Key 复制时首尾少了字符，回去重新复制一次完整的
  5. 网页更新了但 App 里还是旧的 → 手机上是改完代码重新部署后，删掉主屏图标重装一次最省事
⚠️ 换设备、清浏览器缓存之前，先在设置里导出备份留一份，这是唯一的后悔药。
