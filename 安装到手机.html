手机 · 装成 APP 推荐

用手机浏览器打开本页，按下面步骤加到主屏。之后点主屏图标就能像 App 一样全屏打开， 断网也能用（数据在手机本地）。

iPhone / iPad（Safari）
  1. 点底部中间的 分享 按钮（方框＋向上箭头）
  2. 往下找到 「添加到主屏幕」，点它
  3. 右上角点 添加
Android（Chrome / Edge / 华为 / 小米浏览器）
  1. 点右上角 ⋮ 菜单
  2. 选 「添加到主屏幕」 或 「安装应用」
  3. 确认即可
⚠️ 用微信内置浏览器打开的话，右上角菜单里没有「添加到主屏幕」。 请点右上角 ⋯ → 在浏览器打开，再用系统浏览器加到主屏。

电脑 · 加到桌面 / 任务栏 离线可用

电脑上不用装任何东西，用浏览器（Edge 或 Chrome）打开本页就行：

  1. Edge：右上角 ⋯ → 应用 → 将此站点作为应用安装
  2. Chrome：右上角 ⋮ → 投放、保存和共享 → 将网页作为应用安装
  3. 装完会有独立图标，可固定到任务栏 / 桌面，打开没有地址栏，断网也能用

另外网页版本身就有离线缓存，只要打开过一次，之后没网也能进。

电脑 · 本地文件版（可选） 自动备份

想要「数据存成电脑上的一个真实文件」而不是浏览器里时，才用这个。 数据写在 投资实证工作台\data\save.json，每天自动留一份备份。

  1. 在 OneDrive\【我的工作台】\投资实证工作台 这个文件夹里 （注意不是 Windows 桌面），找到 投资实证工作台.bat
  2. 双击它，会弹出独立窗口
  3. 也可以用右键 → 发送到 → 桌面快捷方式，以后从桌面进
⚠️ 这一步不是必须的。日常用网页版就够了，只是网页版的数据存在浏览器里， 清理浏览器数据会丢 —— 记得定期在「设置」里导出备份或开云同步。

多设备同步 可选

想在手机和电脑之间同步同一份数据，在设置里填一组 JSONBin 的 API Key + Bin ID（两边填一样的），就能手动上传/恢复。 不需要同步也可以各用各的。

⚠️ 电脑和手机的本地数据是各存一份的。换设备前先在设置里 「导出备份」或「上传到云端」，不然新设备上是空的。
